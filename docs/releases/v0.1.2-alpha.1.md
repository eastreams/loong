## Highlights
- Strengthened the root `loong` operator path around `onboard`, `ask`, `chat`, and `doctor`.
- Expanded governed runtime seams across delegate delivery, session inspection, trajectory surfaces, and runtime capability flows.
- Hardened memory continuity with provenance-aware recall, staged hydration, pre-assembly systems, and compaction-related runtime truth.
- Broadened gateway-owned and runtime-backed delivery surfaces while keeping operator ownership explicit.
- Extended the shipped tool, provider, onboarding, and release-hardening baseline instead of widening into a second assistant runtime.

## Release Truth

This alpha should be read as a governed local-assistant release, not as a
fully productized platform release.

Shipped product path:

- `loong`
- `loong ask`
- `loong chat`
- `loong onboard`
- `loong doctor`
- `loong gateway run|status|stop`
- task-shaped background task controls over the child-session substrate

Shipped but still transitional:

- additive SDK spine crates (`loong-core`, `loong-plugin-sdk`, `loong-runtime`,
  `loong-app-protocol`, `loong-cli`)
- richer gateway/runtime capability surfaces that are real but not yet the full
  public platform contract

Not the contract of this alpha:

- a second assistant runtime
- full Web UI productization
- full plugin marketplace productization
- a fully productized browser companion write-action surface
